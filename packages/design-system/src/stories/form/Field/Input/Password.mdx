# Password

`Form.Password` provides a way for users to securely enter a password.

Its content is obscured so that it cannot be read, usually by replacing each character with a symbol such as the asterisk ("\*") or a dot ("•").
It will vary depending on the user agent and OS.

## Interactions

- When the user clicks outside the input, the password is not revealed anymore.
