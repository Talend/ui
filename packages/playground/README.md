# Playground

This app is aiming to help demonstrate `ui/container` containers in an environement where we can run a `cmf` app and mock a backend.

It can also be used as a development environment.

## How to use

#### Install

Install dependencies and build the workspace libraries from the repository root before starting the playground:

```sh
cd Talend/ui
pnpm install
pnpm build
pnpm start
```
